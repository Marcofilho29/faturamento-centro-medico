# Dashboard de Faturamento - Centro Médico

Este é um dashboard profissional desenvolvido para visualização e análise de faturamentos por convênio.

## Funcionalidades
- **Visão Geral**: Resumo das métricas principais e distribuição de faturamento atual.
- **Evolução**: Comparativo histórico do desempenho de cada convênio nos últimos 6 meses.
- **Ranking**: Classificação detalhada dos convênios por faturamento total acumulado.

## Tecnologias Utilizadas
- HTML5 / CSS3 (Design Responsivo)
- JavaScript (ES6+)
- [Chart.js](https://www.chartjs.org/) para visualizações de dados interativas.
- Font Awesome para iconografia.
- Google Fonts (Inter) para tipografia moderna.

## Como Visualizar
Basta abrir o arquivo `index.html` em qualquer navegador moderno. Para deploy, a estrutura já está preparada para plataformas como Vercel ou GitHub Pages.
